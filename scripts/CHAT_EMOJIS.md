# 사내메신저 이모티콘

- 대화창 왼쪽 패널: 이모티콘 / 미니이모티콘, 검색, 분류, 최근 사용, 선택 취소 및 전송 전 미리보기.
- 자체 제작 캐릭터 묶음 `새담걸` 23개는 `static/chat-emoji/girl-em/`에 두며, `custom-manifest.json`의 순서와 이름으로 큰 이모티콘 목록 맨 앞에 표시한다. 메시지는 `[새담걸 이모티콘: 오케이]` 형식으로 저장되어 1:1/그룹 대화와 과거 기록에서 동일하게 렌더링된다.
- `새담걸 · 졸려요`는 `g11.png` 이미지를 사용한다.
- 큰 이모티콘은 한 번 클릭하면 전송 전 미리보기로 선택되고, 두 번 클릭하면 작성 중인 초안과 첨부파일을 유지한 채 해당 이모티콘만 즉시 전송한다. `새담걸`은 대화에서 150px로 표시하되 좁은 화면에서는 넘치지 않게 축소한다.
- 대화창에 보여주는 목록은 큰 이모티콘 455개, 미니이모티콘 379개. 전체(큰 이모티콘 4,652개, 미니이모티콘 3,789개)는 너무 많아 약 1/10만 쓴다.
- 움직이는 이모티콘 233개는 저장소에 두지 않고 Google 공식 배포 주소(`fonts.gstatic.com`)에서 바로 불러온다. 512px WebP가 개당 평균 413 KiB라 233개만 해도 94 MiB여서 Render 배포에 올릴 수 없었다. 컬러 SVG 222개는 전부 합쳐 0.6 MiB뿐이라 그대로 서버에서 제공한다. `catalog.json`은 서버에 두는 파일만 경로·해시로 기록하고, 원격 이미지는 주소만 남긴다.
- 사내망이 `fonts.gstatic.com`을 막으면 움직이는 이모티콘만 안 보이고 유니코드 이모지로 대체 표시된다(`.emoji-art.failed`). 컬러 이모티콘과 미니이모티콘은 영향 없음.
- 출처: Google Animated Noto Emoji (CC BY 4.0), OpenMoji 15.1.0 (CC BY-SA 4.0). 표정 분류만 움직이는 이미지와 컬러 이미지를 함께 제공하고, 나머지 분류는 한 가지만 보여준다.
- 노출 목록은 `scripts/chat_emoji_catalog.py`가 정한다. 손으로 고른 234개는 모두 남기고, 나머지는 분류 크기의 제곱근에 비례해 고르게 뽑아 '사람·인사'의 피부색·성별 변형 2,237개가 목록을 덮지 않게 한다. 규칙이 정해져 있어 다시 실행해도 같은 목록이 나온다.
- 패키지 구분 없이 분류 안에서 움직이는 이미지와 컬러 이미지를 함께 제공. 상단은 두 탭과 오른쪽 닫기 버튼, 하단은 새담인트라넷 배너만 표시.
- 별도 패키지 설치나 API 키가 필요하지 않음. 배포 시 `static/chat-emoji/` 전체와 새 CSS/JS 및 템플릿을 함께 반영해야 함. `static/chat-emoji/` 전체 약 5.3 MiB(이미지 0.6 MiB + 원본 메타데이터 캐시 4.1 MiB), 브라우저가 받는 `catalog.js`는 약 78 KiB; 이미지는 지연 로딩하고 목록은 84개씩 추가 표시. 한국어 이름 및 검색어는 Unicode CLDR 46.1 데이터 사용.
- 좁은 독립 팝업은 브라우저가 허용하면 왼쪽으로 320px 확장. 일반 탭, 모바일, 창 크기 변경이 제한된 환경에서는 왼쪽 서랍으로 표시. 닫으면 자동 확장했던 창 크기를 복원하되, 사용자가 창 너비를 바꿨으면 유지.
- 큰 이모티콘은 기존 메시지 본문에 `[움직이는 이모티콘: 활짝]` 또는 `[컬러 이모티콘: 활짝]` 형식으로 저장하고, 등록된 목록과 정확히 일치하는 표시만 로컬 이미지로 렌더링. 외부 URL이나 임의 HTML은 해석하지 않음. DB 변경 없음. 이미지가 없으면 유니코드 이모지로 표시. 기존 대화 호환을 위해 목록의 이름은 중복 없이 유지하고, 이미 발행된 이름을 변경하지 않아야 함.
- 1:1/그룹 대화와 과거 기록에 동일하게 적용. 원본 문자열을 쓰는 알림·검색 요약·복사에도 사람이 읽을 수 있는 이모티콘 이름이 표시됨. 새 코드가 적용되기 전에 이미 열려 있던 대화창은 다시 열어야 이미지로 보임.
- 라이선스 안내는 `static/chat-emoji/credits.html`에 포함하며 하단 새담인트라넷 배너를 눌러 열 수 있음. 이미지 파일 자체는 수정하지 않았으며 파일별 원본 URL 및 해시는 `catalog.json`에 기록. 브라우저용 `catalog.js`에서는 출처·해시를 제외해 전송 크기를 줄임.

## 이미지 갱신

`python scripts/prepare_chat_emojis.py` (Python 표준 라이브러리만 사용, 최초 다운로드 시 인터넷 필요). 기존 파일은 재사용하며 통신 오류가 나면 목록 발행을 중단. 공식 제공 파일이 없는 종류는 해당 패키지에서 제외.

노출 목록만 다시 뽑을 때는 인터넷 없이 `python scripts/chat_emoji_catalog.py` 실행. `custom-manifest.json`의 자체 제작 이모티콘을 `catalog.json`에 동기화한 뒤 `catalog.js`를 다시 만든다. 개수를 바꾸려면 같은 파일의 `TARGET_ENTRIES`를 수정.

`python scripts/chat_emoji_catalog.py --prune`을 붙이면 서버에서 제공하지 않는 이미지 파일(목록에서 빠진 것 + 원격으로 불러오는 `REMOTE_PACKS`)을 지우고 `catalog.json`도 그에 맞게 줄인다. 여러 번 실행해도 결과가 같다. 지운 이미지는 `prepare_chat_emojis.py`를 다시 돌려야 돌아오므로(인터넷 필요), 개수를 늘릴 계획이면 `--prune` 없이 실행할 것.

움직이는 이모티콘을 다시 서버에서 제공하려면 `chat_emoji_catalog.py`의 `REMOTE_PACKS`를 비우고 `prepare_chat_emojis.py`를 실행한다. 저장소가 약 94 MiB 늘어난다.

## 검증

`node scripts/check_chat_emojis.cjs` (개발 검증에만 Playwright 및 Chrome 필요). `PLAYWRIGHT_MODULE` 환경변수로 설치된 Playwright 경로 지정 가능. `EMOJI_QA_OUTPUT`으로 화면 캡처 저장 경로 지정 가능.

실제 템플릿을 테스트용 값으로 채우고 브라우저에서 실행하며, API 응답을 가상 처리하므로 운영 DB와 실제 메시지에는 접근하지 않음. 이미지 해시·애니메이션 여부, 검색·탭·커서 삽입·최근 사용, 실패 후 재시도·중복전송 방지, 1:1/그룹 수신 렌더링, 이미지 실패 대체 표시, 데스크톱/모바일 배치를 검증.
